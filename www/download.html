The same Kinora you know, without the browser's limits. Free for Android and Windows.

Install help

Android: open the file, allow installs from your browser if asked. Play Protect may ask to scan the app because it is not from the Play Store; choose to scan or install anyway.

Windows: run the installer. If SmartScreen appears, choose More info, then Run anyway.
